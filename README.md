# Mannona-try-e-commerece 🚀

تطبيق فلاتر تجريبي وسهل لتجربة والتعامل مع جميع وظائف الـ API الخاصة بالـ E-commerce عبر مكتبة `Dio`.

## المميزات وطريقة التجربة:
- يحتوي التطبيق على واجهة بسيطة مقسمة لتبويبات (Tabs):
  1. **Users & Auth**: تسجيل حساب، تسجيل الدخول، تحديث الملف الشخصي، جلب بيانات المستخدم، تجديد التوكن (Refresh Token)، وحذف الحساب.
  2. **Products**: عرض المنتجات، البحث، الأكثر مبيعاً (Best Sellers)، الأعلى تقييماً (Top Rated)، إضافة منتج، تعديل، حذف، والإضافة للمفضلة.
  3. **Categories & Sliders**: استعراض وإضافة وتعديل وحذف الأقسام (Categories) والسلايدرز (Sliders).
  4. **Orders**: استعراض الطلبات، عمل طلب جديد (Place Order)، إلغاء طلب، وإكمال طلب.
- شاشة إخراج (Response Console) بالأسفل لعرض الـ JSON والاستجابة القادمة من الـ API مباشرة في التطبيق.
- يدعم التعديل السريع على الـ `Base URL` والـ `Token` مباشرة من التطبيق!

## متطلبات التشغيل:
```bash
flutter pub get
flutter run
```
